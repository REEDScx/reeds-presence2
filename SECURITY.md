# Política de segurança

Não publique vulnerabilidades exploráveis, credenciais, tokens, chaves de assinatura ou dados pessoais em issues ou pull requests.

Reporte vulnerabilidades de maneira privada usando **GitHub → Security → Report a vulnerability**, se a opção estiver habilitada. Caso não esteja, solicite um canal privado ao mantenedor sem divulgar detalhes sensíveis publicamente.

Inclua versão afetada, impacto, passos de reprodução e evidências sanitizadas. Não há prazo de resposta garantido. Nunca anexe keystores, tokens, logs privados ou APKs alterados.

Antes de qualquer mudança de visibilidade ou publicação, audite arquivos e **todo o histórico Git**. `.gitignore` não remove segredos já commitados; revogue credenciais expostas e reescreva o histórico quando necessário.
