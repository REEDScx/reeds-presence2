# Contribuindo

Este repositório público distribui releases e documentação do REEDS Presence; o código-fonte do aplicativo está em um repositório privado. Pull requests aqui devem tratar de documentação, templates, metadados públicos e automações seguras. Não envie código-fonte privado, SDKs proprietários, APKs não aprovados ou credenciais.

1. Abra uma issue para mudanças grandes.
2. Crie um fork e uma branch descritiva.
3. Faça alterações pequenas e verificáveis; revise links e conteúdo sensível.
4. Abra um pull request usando o template, com testes e evidências.
5. Aguarde revisão e aprovação dos mantenedores.

Ao contribuir, você concorda que sua contribuição enviada a este repositório pode ser distribuída sob a licença aplicável. A licença MIT neste repositório **não licencia o código-fonte privado nem os APKs, marcas, SDKs ou ativos de terceiros**.
